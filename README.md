# CoreForge

Improved core training app with dual timer/reps mode, progressive 30-day plans, custom workout generator, and progress tracking.

## Key Features
- Dual mode on every exercise: Timer or Reps
- Beginner / Intermediate / Advanced 30-day plans
- Custom Workout Generator
- Streak and body metrics progress
- 7-day free trial then $29.99/year (Pro)
